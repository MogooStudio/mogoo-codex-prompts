Mogoo 常用提示词

把常用指令收藏在 Codex 侧栏。需要时点一下，正文就会追加到当前聊天草稿，编辑后即可发送。

安装到 Codex

需要支持插件命令的 Codex、Git 和 Python 3.10 或更高版本。在终端运行以下两行命令。

codex plugin marketplace add https://github.com/MogooStudio/mogoo-codex-prompts.git --ref main --json
codex plugin add mogoo-codex-prompts@mogoo-codex-prompts --json

打开侧栏，收藏第一条指令

在新聊天中输入「打开常用提示词面板」，点击「快速收藏」并粘贴正文。各项目共用这份本机收藏，可以按分类浏览，也可以搜索标题或正文。

点击面板底部的版本号可检查更新。查看更新记录
